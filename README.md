Termux Dotfiles
===============
My Personal Termux dotfiles for Android devices.

Usage
-----
To install the dotfiles
```sh
> ./install.sh
```
> Warning: Make sure you backup your home directory for safety.

For creating backup of existing dotfiles
```sh
> ./backup.sh
```
> Note: This script does not backup your home directory or config files.

Backup Contents
---------------
- **.termux** - Termux app configs.
- **.vimrc** - vim editor config.
- **glow** - Glow package config.
